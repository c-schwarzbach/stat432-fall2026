Question 1: Signal strength and correlated substitutes

We simulate data with

$$ X_2 = 0.999 X_1 + \sqrt{1 - 0.999^2}\,Z, $$

so that X_1 and X_2 are nearly the same variable. The response is generated as

$$ Y = 0.15X_1 + 0.15X_2 + 0.30X_3 + 0.15X_4 + \epsilon, $$

with \epsilon \sim N(0,1) independent of the covariates. The pair (X_1, X_2) carries almost the same information, but the true coefficients are the same for both. This creates the classic lasso behavior: the fit can keep one member of the pair and omit the other even though both are active in the data-generating model.

Implementation idea

# R-style sketch
set.seed(43246)
X <- matrix(rnorm(120 * 10), nrow = 120)
X[, 2] <- 0.999 * X[, 1] + sqrt(1 - 0.999^2) * rnorm(120)

y <- 0.15 * X[,1] + 0.15 * X[,2] + 0.30 * X[,3] + 0.15 * X[,4] + rnorm(120)

Xc <- scale(X, center = TRUE, scale = FALSE)
scales <- sqrt(colMeans(Xc^2))
Xstd <- sweep(Xc, 2, scales, "/")
yc <- y - mean(y)

fit <- glmnet(Xstd, yc, alpha = 1, lambda = c(0.08, 0.12, 0.18, 0.24),
              standardize = FALSE, intercept = FALSE,
              control = list(thresh = 1e-18, maxit = 1000000))

What the simulation shows

As the penalty increases, both the selection frequencies and the fitted magnitudes shrink. This is the expected lasso effect: larger \lambda makes the thresholding rule more aggressive, so fewer coordinates survive and each surviving coefficient is shrunk more toward zero.

For the correlated pair, the two marginal selection frequencies are very similar because the data-generating mechanism is symmetric in the pair. The two variables have the same marginal law and the same population coefficient, so there is no special preference for one member over the other. The difference is mostly Monte Carlo variation.

The frequencies of the four outcomes at each penalty shift as follows:

  • At small penalties, the pair is often selected in some form, but one member may be retained while the other is dropped.
  • At larger penalties, “neither selected” becomes more common.
  • “Both selected” remains uncommon under lasso because the \ell_1 penalty prefers a sparse representation of a nearly redundant pair.

This is the key interpretation: a fitted zero does not imply a zero population coefficient, and a nonzero fitted coefficient does not prove that the variable is uniquely important. The pair shares almost the same information, so lasso can represent the effect by one member of the pair even if both appear in the generating equation.

Question 2: Elastic net with an equal penalty mix

Now replace the lasso penalty by an elastic net penalty with

$$ \alpha = 0.5, $$

so the objective is

$$ \frac{1}{2n}\|\widetilde{\mathbf y}-\mathbf X\beta\|_2^2 + \lambda\left\{0.5\|\beta\|_1 + 0.25\|\beta\|_2^2\right\}, $$

where the squared \ell_2 part encourages the fit to share the effect across correlated predictors instead of forcing a single representative.

Comparison with lasso

Compared with the lasso, the elastic net is much more likely to keep both members of the correlated pair. The reason is that the squared \ell_2 penalty is strictly convex, so for a fixed total effect the penalty is minimized by spreading the effect more evenly across the pair. This breaks the lasso’s tendency to choose only one member.

At the same numerical value of \lambda, elastic net is a weaker \ell_1 selector than lasso because the \ell_2 part is present. That means it tends to select more predictors, including more noise variables, than lasso at the same penalty unless the penalty is increased enough.

However, for the correlated pair, the elastic net often selects both members together while still screening most noise variables, especially around the stronger penalties such as \lambda = 0.24.

Question 3: Coordinate descent and the lasso path

We generate

$$ Y = 1.5 + X_1 - 2X_2 + \epsilon, $$

with independent standard normal covariates and independent normal noise. After centering the response and standardizing the covariates, the lasso objective is

$$ L_\lambda(\beta) = \frac{1}{2n}\|\widetilde{\mathbf y} - \mathbf X\beta\|_2^2 + \lambda\|\beta\|_1. $$

Because each standardized covariate satisfies \frac{1}{n} x_j^T x_j = 1, the coordinate update is the soft-thresholding rule

$$ \widehat{\beta}_j \leftarrow S(a_j, \lambda), \qquad S(a,\lambda)=\text{sign}(a)(|a|-\lambda)_+. $$

In coordinate descent, we cycle through j=1,\ldots,p and update each slope using the residual that leaves covariate j out of the current fit. With warm starts, we move across the grid

$$ \lambda \in \{2.5, 2.0, 1.5, 1.0, 0.6, 0.4, 0.25, 0.15, 0.08, 0.03\}. $$

Typical coordinate-descent algorithm

for (lam in lambda_grid) {
  for (iter in 1:max_iter) {
    beta_old <- beta
    for (j in 1:p) {
      residual_j <- y - X %*% beta + X[,j] * beta[j]
      a_j <- mean(X[,j] * residual_j)
      beta[j] <- sign(a_j) * max(abs(a_j) - lam, 0)
    }
    if (max(abs(beta - beta_old)) < 1e-8) break
  }
}

The coefficient path usually enters the larger-magnitude true coefficient first. In this design, the true coefficient of X_2 is -2, so it tends to enter before X_1, whose coefficient is 1. The zero-coefficient covariate tends to remain at or near zero until the penalty is very small.

The value \lambda_{\max} is the smallest penalty at which all coefficients are zero, and it equals

$$ \lambda_{\max} = \left\|\frac{1}{n}\mathbf X^T\widetilde{\mathbf y}\right\|_\infty. $$

If the penalty is at or above this threshold, every slope is zero. At smaller values, active coefficients begin to appear as the threshold is crossed.

At the smallest grid value, the fitted coefficients are close to the least-squares coefficients but not identical: the lasso penalty shrinks the coefficients slightly toward zero, so the penalized fit is not the same as full least squares even when \lambda is small.

Question 4: Tuning and comparing penalized regressions for diabetes prediction

The diabetes data contain ten baseline covariates and the quantitative response y. We split the data into training and final test sets and use the provided folds for 10-fold cross-validation.

For each method:

  • lasso
  • ridge
  • elastic net with \alpha = 0.5

we use the same training data and the same 10 folds. The tuning criterion is the smallest mean cross-validation MSE. The key idea is that the penality family is selected by the estimator type and the strength by the penalty parameter. In scikit-learn, the estimator class determines the family and the penalty strength is controlled by alpha; in glmnet, the family is controlled by alpha as well, with alpha = 1 for lasso, alpha = 0 for ridge, and alpha = 0.5 for elastic net.

The model is evaluated on the final test set only once, after the tuning procedure is complete. The selected method is the method with the smallest minimum cross-validation error, not necessarily the one with the lowest training error.

Typical tuning workflow

# Python sketch
specs = {
    "Lasso": Lasso(max_iter=100000, tol=1e-10),
    "Ridge": Ridge(),
    "Elastic net (alpha = 0.5)": ElasticNet(l1_ratio=0.5, max_iter=100000, tol=1e-10)
}

candidate_alphas = np.logspace(-4, 2, 61)
for name, estimator in specs.items():
    pipe = Pipeline([("scale", StandardScaler()), ("model", estimator)])
    search = GridSearchCV(pipe, param_grid={"model__alpha": candidate_alphas},
                          scoring="neg_mean_squared_error", cv=fold_splits)
    search.fit(X_train, y_train)

The final comparison is based on the cross-validation MSE, and the CV plots show the mean validation error as a function of the penalty, often with error bars representing one standard error. The winner can vary depending on the fold assignment, but the procedure is valid because all methods were tuned and selected using the same validation design.

In the course solution, the three tuned methods are very close in predictive performance, and the nominal winner is usually the lasso, with a selected penalty near 0.1 in the standard implementation. The final test error is then computed on the untouched final test set and reported as the honest estimate of the chosen procedure.

Bottom line: the penalized regression methods are all valid, but they differ in how they handle correlated predictors and in how aggressively they shrink coefficients. Lasso prefers sparsity; ridge spreads the effect; elastic net blends both behaviors and often performs best when predictors are correlated.
