Python imports and data setup

The code below follows the Python solution in the Homework 6 Quarto document. It uses the same split recorded in breast-cancer-split.csv, so that the results line up with the course solution.

from pathlib import Path
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import roc_curve, roc_auc_score

data_dir = Path("data")
if not (data_dir / "breast-cancer.csv").exists():
    data_dir = Path("practice/weeks/week-06/data")
data = pd.read_csv(data_dir / "breast-cancer.csv")
# Use the split generated with seed 432 in the R solution.
split = pd.read_csv(data_dir / "breast-cancer-split.csv")
train = data.loc[split["split"].eq("train")]
test = data.loc[split["split"].eq("test")]
predictors = ["mean_radius", "mean_texture", "mean_smoothness"]

x_bar = train[predictors].mean()
s = train[predictors].std(ddof=1)
X_train = ((train[predictors] - x_bar) / s).to_numpy()
X_test = ((test[predictors] - x_bar) / s).to_numpy()
y_train = train["y"].to_numpy()
y_test = test["y"].to_numpy()
Question 1

Compare KNN and logistic regression

We compare the models using their estimated probabilities of malignancy, not class predictions at a single cutoff. For KNN, this probability is the proportion of malignant cases among the k nearest training observations.

Fit ordinary logistic regression and the five KNN models. Logistic regression uses an intercept and no penalty, while KNN uses uniform neighbor weights and Euclidean distance.

fit = LogisticRegression(C=np.inf, solver="lbfgs", fit_intercept=True,
                         tol=1e-10, max_iter=1000)
fit.fit(X_train, y_train)
k_values = [5, 15, 25, 35, 45]
model_names = ["Logistic regression"] + [f"KNN, k = {k}" for k in k_values]
p_test = np.empty((len(y_test), len(model_names)))
p_test[:, 0] = fit.predict_proba(X_test)[:, 1]
for m, k in enumerate(k_values):
    knn_fit = KNeighborsClassifier(n_neighbors=k, weights="uniform",
                                   metric="euclidean", algorithm="brute")
    knn_fit.fit(X_train, y_train)
    p_test[:, m + 1] = knn_fit.predict_proba(X_test)[:, 1]

auc_test = [roc_auc_score(y_test, p_test[:, m])
            for m in range(len(model_names))]
print(pd.DataFrame({"Model": model_names, "Test AUC": auc_test})
      .round(4).to_string(index=False))

Interpretation: The ROC curves show how each model ranks malignant versus benign cases on the test set. A larger AUC indicates better discrimination. In this split, the logistic regression model gives the strongest ranking, while KNN behaves best near the larger neighborhood sizes.
Question 2

Training and test ROC curves

Use the same data split and standardization as in Question 1. For each value of k, fit KNN on the training data and compute probabilities for both the training and the test observations.

k_values = [1, 3, 5, 10, 20]
p_train = np.empty((len(y_train), len(k_values)))
p_test = np.empty((len(y_test), len(k_values)))
auc_train = np.empty(len(k_values))
auc_test = np.empty(len(k_values))
for m, k in enumerate(k_values):
    knn_fit = KNeighborsClassifier(n_neighbors=k, weights="uniform",
                                   metric="euclidean", algorithm="brute")
    knn_fit.fit(X_train, y_train)
    # Passing X_train explicitly includes each observation itself.
    p_train[:, m] = knn_fit.predict_proba(X_train)[:, 1]
    p_test[:, m] = knn_fit.predict_proba(X_test)[:, 1]
    auc_train[m] = roc_auc_score(y_train, p_train[:, m])
    auc_test[m] = roc_auc_score(y_test, p_test[:, m])
print(pd.DataFrame({"k": k_values, "Training AUC": auc_train,
                    "Test AUC": auc_test}).round(4).to_string(index=False))

The key pattern is that training AUC is much more optimistic than test AUC, especially when k is small. At k = 1, each training observation is its own nearest neighbor, so the fitted probability is exactly its observed response: 0 or 1. This makes the training AUC equal to 1.0000, but it does not mean that the model will predict well on new observations, because the test data were not used to fit the model.

Why the training/test gap matters: Training performance is optimistic because the same observations are used both to fit and to evaluate the model. As k increases, the fitted probabilities are smoothed and become less variable, which typically reduces this optimism and improves test performance up to a point. 
fig, axes = plt.subplots(2, 3, figsize=(10, 7))

           xlabel="False-positive rate", ylabel="True-positive rate")
    ax.legend(loc="lower right", frameon=False, fontsize=8)
axes.flat[-1].set_visible(False)
fig.tight_layout()
plt.show()

The training ROC curve for k = 1 is almost perfect because each observation is ranked against itself. The test curve is lower because it evaluates the model on cases that were not seen during fitting. A larger neighborhood generally reduces this gap, but if k gets too large, the model may become too smooth and lose local structure.
